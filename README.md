# 📅 BCAD Year 3 Dashboard

A responsive **Semester 2 academic dashboard** for BCAD Year 3 at Emeris Durban North, bringing PAS assessment dates, a live deadline countdown, today's classes, the weekly timetable, and course links together in one place.

### 🌐 [Open the Live Dashboard](https://zenwyn-naicker.github.io/bcad-dashboard/)

## ✨ Features

* 🧭 **Sidebar navigation** between Overview, Timetable, and Deadlines, with a menu drawer on mobile
* ⏳ **Live countdown** to the next deadline, with **Mark as submitted** (and undo) so it moves on to the next one
* 📍 **Today panel** showing current and upcoming classes with time left, plus the next class when the day is done
* 📅 **PAS calendar** with colour-coded module deadlines and tap-to-view details for each assessment
* ✅ **Deadlines list** grouped by month, with module filters, submitted ticks, and past deadlines tucked away
* 🗓️ **Weekly timetable** with classes, times, venues, lecturers, academic events, and a live "now" line
* 👥 **Group 1 and Group 2 switching** with group-specific timetable and lecturer information
* 📚 **Module shortcuts** to each course on myStudies
* 🔗 **Quick links** to myStudies, MyEmeris, VC Student Portal, MyVC Intranet, and Student Materials, plus your own custom links
* 📄 Direct links to the **official PAS and timetable** on SharePoint
* 🌙 **Light and dark modes** with saved preferences
* 💾 Group, theme, submitted ticks, and custom links are **saved on your device**
* 📱 **Responsive layout** for desktop, laptop, tablet, and mobile
* ⌨️ **Keyboard shortcuts**: `1` `2` `3` to switch views, `G` to switch group, `T` for this week, and arrow keys for weeks and months
