# 📅 BCAD Year 3 Dashboard

A responsive **Semester 2 academic dashboard** for BCAD Year 3 at Emeris Durban North, combining PAS assessment dates, assignment countdowns, module resources, and weekly timetables in one place.

### 🌐 [Open the Live Dashboard](https://zenwyn-naicker.github.io/bcad-dashboard/)

## ✨ Features

* 📅 **PAS assessment calendar** with colour-coded module deadlines
* ⏳ **Live countdown** to the next upcoming assessment
* 🗓️ **Weekly timetable** with classes, times, venues, lecturers, and academic events
* 👥 **Group 1 and Group 2 switching** with group-specific timetable and lecturer information
* 📚 **Quick links to module materials** on SharePoint
* 🔗 Direct links to the **official PAS and timetable**
* 🌙 **Light and dark modes** with saved preferences
* 📍 Automatically highlights the **current date** and opens the relevant calendar month and timetable week
* 📱 **Responsive layout** for desktop, tablet, and mobile
* ⌨️ Keyboard-friendly navigation and accessible controls
